# Plugin usage plan

OpenCareer remains an offline-first WinUI 3 desktop application. Connected tools improve development, validation and data preparation without silently becoming runtime dependencies.

- **Data Analytics / Wolfram**: calibrate conflict frequency, duration, airport recovery and economic spillovers.
- **Figma**: refine World Map / Conflict Operations UI before XAML implementation.
- **Kling AI**: optional non-authoritative visual concept work.
- **Notion**: optional planning/research mirror; Git Markdown remains canonical engineering handoff.
- **Supabase**: optional development data staging or collaborative research store, not required by the player runtime.
- **Vercel**: optional internal preview/tooling only; not part of the shipping WinUI architecture.
- **ForeFlight Mobile**: human workflow/flight-planning reference when connector access permits; never a runtime dependency.
- **Web research**: current external facts require dated provenance.

Do not add a cloud service to production merely because a connector is available.
